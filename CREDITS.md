## Audio (CC0 1.0, copied from the CubeInvasion project)
All sound is recorded audio; nothing is synthesized in code (GDD §13). Source pages and licenses as recorded in
`CubeInvasion/AUDIO_LICENSES.md`; pack license texts sit next to the files in `Assets/PlanetDefender/Audio/`.

## Planet surface maps
`Assets/PlanetDefender/Art/Planets/2k_*.jpg` come from the original 2020 project (`_Legacy2019/Assets/texture set`).
Their file names match the Solar System Scope texture set (https://www.solarsystemscope.com/textures/,
CC BY 4.0, based on NASA imagery). **Confirm that source before release**; if correct, keep this attribution
in the game's store description or credits. `uranus_generated.png` is generated by the editor builder.
